Le **portefeuille** est un solde prépayé stocké dans votre compte KwikTalk. Il
sert à payer votre abonnement sans ressaisir de carte à chaque fois.

Accès : menu de gauche → **Portefeuille**

::u-alert{color="info" icon="i-lucide-info"}
Le portefeuille est **distinct** de l'abonnement : l'abonnement est le plan que
vous avez choisi, le portefeuille est l'argent disponible pour le payer.
::

## Recharger

1. **Portefeuille → Recharger**.
2. Saisissez le **montant du rechargement**.
3. Choisissez le moyen de paiement proposé (carte bancaire, ou carte et mobile
   money selon votre pays).
4. Validez et suivez l'instruction de paiement.

Le solde est crédité dès la confirmation du paiement. Si le solde n'apparaît pas
tout de suite, rechargez la page : certains moyens de paiement confirment avec
quelques minutes de décalage.

## Votre historique

**Historique des transactions** liste chaque mouvement : rechargement, paiement
d'abonnement, remboursement. Chaque ligne indique le montant, la date et le
moyen utilisé — c'est votre justificatif comptable côté portefeuille, distinct
des **factures**.

## Payer un abonnement avec le solde

Au moment de souscrire ou de changer de plan, choisissez **Portefeuille interne**
comme moyen de paiement : le montant est déduit du solde, immédiatement.

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
Si votre solde est insuffisant, le paiement est refusé. Rechargez d'abord, puis
relancez la souscription.
::

## Bon à savoir

- Un rechargement n'expire pas : le solde reste disponible tant que votre compte
  existe.
- Le portefeuille ne se rembourse pas automatiquement. Pour un remboursement,
  contactez le support.
- **Pendant une assistance technique** (un administrateur connecté à votre
  compte), les paiements et rechargements sont bloqués par sécurité. Vos données
  restent visibles, votre argent n'est pas manipulable.
