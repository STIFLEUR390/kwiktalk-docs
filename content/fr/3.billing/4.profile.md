Accès : menu utilisateur → **Paramètres**

## Profil

Vous pouvez modifier :

- votre **nom** ;
- votre **adresse e-mail** — si vous la changez, il faut la confirmer à nouveau ;
- votre **numéro WhatsApp** — utilisé pour vous joindre, pas pour envoyer vos
  campagnes (celles-ci utilisent les instances).

Si l'interface signale que votre e-mail **n'est pas vérifié**, un lien permet de
renvoyer l'e-mail de confirmation.

## Sécurité

### Changer de mot de passe

Saisissez votre **mot de passe actuel**, le **nouveau**, puis sa confirmation.
Choisissez une phrase de passe longue plutôt qu'un mot court avec des chiffres
substitués.

### Double authentification (2FA)

1. **Sécurité → Activer la 2FA**.
2. Scannez le QR code avec une application d'authentification (Google
   Authenticator, Authy, 1Password…).
3. Saisissez le code à 6 chiffres pour confirmer.
4. **Conservez les codes de secours** affichés : sans eux, une perte de téléphone
   vous enferme dehors.

Une fois activée, chaque connexion demande le mot de passe **puis** le code.

::u-alert{color="warning" icon="i-lucide-key-round"}
Si vous vous connectez via Authentik ou Keycloak, la double authentification se
gère dans votre fournisseur d'identité, pas ici.
::

## Niveau de protection anti-ban

Ce réglage décide de la sévérité avec laquelle KwikTalk freine vos envois pour
protéger votre numéro.

| Niveau | Effet |
|---|---|
| **Protection complète** (par défaut) | KwikTalk limite automatiquement le rythme d'envoi, met en pause une campagne trop rapide, et bloque les envois tant qu'un numéro est suspendu |
| **Protection partielle** | Les quotas préventifs sont levés, mais KwikTalk réagit encore à une vraie suspension (mise en pause, alerte) |
| **Protection désactivée** | Aucun frein, aucune pause automatique, même pendant une suspension |

::u-alert{color="warning" icon="i-lucide-shield-alert"}
Ne désactivez la protection que si vous acceptez le risque : **un numéro peut
être suspendu définitivement**. En cas de doute, laissez la protection complète.
Voir [Éviter le bannissement](/fr/help/anti-ban).
::

## Apparence

Le thème **clair**, **sombre** ou **système** se choisit dans les paramètres
d'apparence. Votre choix est conservé sur votre compte.

## Supprimer votre compte

**Supprimer le compte** efface votre profil et toutes ses ressources : instances,
contacts, campagnes, modèles. **Cette action est irréversible.**

Avant de supprimer :

1. téléchargez vos dernières [factures](/fr/billing/subscription) si vous en avez
   besoin ;
2. exportez la liste de vos contacts ;
3. vérifiez que personne d'autre dans votre organisation n'utilise le compte.
