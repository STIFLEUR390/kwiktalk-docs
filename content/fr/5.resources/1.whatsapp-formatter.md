Outil **gratuit et sans compte** : rédigez votre message, formatez-le, copiez-le
tel quel dans WhatsApp.

Accès : **`/outils/formatteur-whatsapp`**

::u-alert{color="success" icon="i-lucide-gift"}
Aucune inscription, aucune connexion. L'outil fonctionne pour tout le monde, y
compris sans compte KwikTalk.
::

## La syntaxe

WhatsApp n'a pas de barre d'outils : le formatage se fait avec des caractères
spéciaux. Le formatteur les applique pour vous.

| Format | Syntaxe WhatsApp | Rendu |
|---|---|---|
| **Gras** | `*texte*` | **texte** |
| *Italique* | `_texte_` | *texte* |
| ~~Barré~~ | `~texte~` | ~~texte~~ |
| Liste | lignes `•` | liste à puces |
| Citation | ligne `> ` | citation |

::u-alert{type="info" icon="i-lucide-info"}
Les listes et les citations WhatsApp sont gérées en plus des trois styles
caractère. Tout est produit au format natif : une fois collé, WhatsApp affiche
directement le rendu.
::

## Comment l'utiliser

1. **Votre texte** — saisissez ou collez votre message dans la zone de gauche.
2. Appliquez **Gras**, **Italique** ou **Barré** sur la sélection.
3. Le **Résultat formaté** s'affiche à droite, avec l'aperçu du rendu WhatsApp.
4. Cliquez sur **Copier** — le message part dans le presse-papiers au format
   WhatsApp.

Actions disponibles : **Copier**, **Effacer**, **Aperçu**, et un **Exemple** pour
voir tout de suite le fonctionnement.

## Le compteur de caractères

L'outil affiche le **nombre de caractères** de votre message, et rappelle en
permanence :

::u-alert{color="warning" icon="i-lucide-ruler"}
**Limite de message WhatsApp : 4096 caractères.**
::

Au-delà, WhatsApp tronque. C'est aussi la limite appliquée à l'API KwikTalk
(champ `message`, 4096 caractères) — voir
[Applications API](/fr/integrations/api-applications).

::u-alert{type="info" icon="i-lucide-lightbulb"}
Le compteur compte **les caractères formatage compris** (`*`, `_`, `~`). Un texte
visuellement court peut donc atteindre la limite plus vite qu'il n'y paraît —
copiez d'abord, puis vérifiez.
::
