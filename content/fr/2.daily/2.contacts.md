Une fois vos contacts importés (voir
[Importer vos contacts](/fr/start/import-contacts)), cette page sert à les
maintenir : corriger un numéro, revalider, ranger dans un groupe, supprimer.

Accès : menu de gauche → **Contacts**, et **Groupes de contacts**

## La liste des contacts

Chaque ligne affiche le nom, le numéro, le statut de validation, les groupes et
l'instance associée. La recherche filtre sur le nom et le numéro ; le filtre par
groupes permet de travailler sur un sous-ensemble.

### Actions sur un contact

| Action | Où |
|---|---|
| Voir la fiche | Cliquer sur la ligne |
| Modifier nom, numéro, groupes | **Modifier** |
| Valider un numéro | **Valider** sur la ligne, ou **Valider la sélection** après avoir coché plusieurs lignes |
| Supprimer | **Supprimer** sur la ligne |

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
**Changer le numéro d'un contact remet son statut à « En attente ».** L'ancienne
validation ne vaut plus : il faut revalider.
::

### Actions sur une sélection

Cochez plusieurs contacts pour :

- **Valider la sélection** — vérifie les numéros sur WhatsApp ;
- **Synchroniser les groupes** — ajoute ou retire les contacts cochés de
  plusieurs groupes en une fois ;
- **Retirer de tous les groupes** — sans supprimer les contacts ;
- **Supprimer** — suppression définitive.

**Supprimer tous les contacts** vide votre base d'un coup. Cette action est
irréversible : elle ne supprime pas les campagnes déjà envoyées, mais elle coupe
net votre liste de diffusion.

## Importer et exporter

L'import se fait depuis **Contacts → Importer** : voir
[Importer vos contacts](/fr/start/import-contacts) pour le format du fichier. Un
fichier d'exemple est téléchargeable depuis cette page.

## Valider les numéros

Un contact **En attente** n'a pas encore été vérifié sur WhatsApp. Le bouton de
validation interroge WhatsApp numéro par numéro et bascule le statut vers
**Validé** ou **Invalide**.

::u-alert{color="info" icon="i-lucide-gauge"}
Comptez environ une seconde par contact. Sur une grosse base, validez par lots
de quelques centaines : une validation de 5 000 contacts d'un seul coup prend
plus d'une heure et peut être interrompue.
::

## Groupes de contacts

Un groupe est une étiquette nommée. Un contact peut appartenir à plusieurs
groupes ; une campagne cible un ou plusieurs groupes.

### Créer un groupe

1. **Groupes de contacts → Créer**.
2. Donnez-lui un nom explicite : « Clients Abidjan », « Prospects janvier »,
   « Boutique Cocody ». Évitez « tous » : un groupe trop large ne sert à rien.
3. Ajoutez les contacts depuis la fiche du groupe, ou depuis la liste des
   contacts avec **Synchroniser les groupes**.

### Bon usage

- Un groupe = **une cible commerciale**, pas une catégorie technique.
- Créez un groupe par opération ponctuelle (« Promo Noël 2026 ») et supprimez-le
  après, pour ne pas accumuler.
- Avant une campagne sensible, créez un petit groupe de test avec votre propre
  numéro et deux ou trois clients de confiance.

## Bonnes pratiques

- **Ne stockez que des contacts ayant accepté** de recevoir vos messages.
- Corrigez les numéros invalides au lieu de les laisser : ils produisent des
  échecs qui abîment la réputation de votre numéro.
- Un contact supprimé ne peut pas être restauré. Exportez votre liste si vous
  voulez la garder.
