Pour écrire à **une seule personne** — un client qui vous a laissé un numéro, une
réponse à une question — utilisez les messages individuels. Pour un envoi à
plusieurs contacts, utilisez une [campagne](/fr/daily/campaigns).

Accès : menu de gauche → **Messages** → **Envoyer un message**

## Envoyer un message

1. Choisissez l'**instance WhatsApp** d'envoi.
2. Saisissez le **numéro de téléphone** du destinataire, au format international
   **sans le `+`** (`2250701020304`).
3. Choisissez le **type** : **Texte**, **Image**, **Document** ou **Audio**.
4. Rédigez le **contenu** — pour un média, ajoutez une **légende**.
5. Cliquez sur **Envoyer le message**.

::u-alert{color="info" icon="i-lucide-type"}
Un message de texte est limité à **4 096 caractères**. Le compteur sous le champ
indique où vous en êtes.
::

### Envoyer un média

Deux méthodes, au choix :

- **Importer un fichier** depuis votre ordinateur (image : JPG, PNG, GIF… —
  document : PDF, DOC, DOCX… — audio) ;
- **Coller l'URL** publique du média, si le fichier est déjà hébergé.

Le **nom du fichier** est déduit automatiquement du fichier ou de l'URL.

## La liste des messages

Chaque message envoyé est conservé avec son statut :

| Statut | Signification |
|---|---|
| **En attente** | Pas encore transmis |
| **Envoi** | Transmis à WhatsApp |
| **Envoyé** | Sorti de votre numéro |
| **Délivré** | Arrivé sur le téléphone du destinataire |
| **Lu** | Ouvert par le destinataire |
| **Échec** | Non remis (numéro invalide, instance déconnectée…) |

La liste se filtre par statut, par type, par instance et par recherche sur le
numéro ou le contenu. La fiche d'un message détaille le destinataire, le média,
l'instance utilisée et, en cas d'échec, le **message d'erreur**.

## Message individuel ou campagne ?

| | Message individuel | Campagne |
|---|---|---|
| Destinataires | Un seul | Des groupes entiers |
| Contenu | Libre ou modèle | Modèle obligatoire |
| Délai géré par KwikTalk | Non | Oui (3 à 10 s) |
| Planification | Non | Oui |
| Suivi de progression | Non | Oui |

Un envoi massif en messages individuels n'est pas protégé par le rythme d'une
campagne : pour plusieurs dizaines de destinataires, créez une campagne.
