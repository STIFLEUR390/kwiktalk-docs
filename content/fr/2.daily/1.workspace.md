Une fois votre numéro connecté, tout se passe dans le menu de gauche. Voici ce
que contient chaque entrée.

| Entrée du menu | Ce que vous y faites | Page |
|---|---|---|
| **Tableau de bord** | L'état de votre compte en un écran | [Tableau de bord](/fr/daily/dashboard) |
| **WhatsApp** | Brancher et surveiller vos numéros | [Connecter votre numéro](/fr/start/connect-whatsapp) |
| **Contacts** | Ajouter, importer, valider vos contacts | [Contacts et groupes](/fr/daily/contacts) |
| **Groupes de contacts** | Ranger les contacts par cible commerciale | [Contacts et groupes](/fr/daily/contacts) |
| **Modèles de messages** | Écrire les messages réutilisables | [Modèles de messages](/fr/daily/templates) |
| **Messages** | Envoyer à un seul destinataire | [Messages individuels](/fr/daily/messages) |
| **Campagnes de messages** | Envoyer à un ensemble de contacts | [Campagnes](/fr/daily/campaigns) |
| **Messages WhatsApp** | Lire ce que vos clients ont répondu | [Messages reçus](/fr/daily/inbox) |
| **Chatbot** | Répondre automatiquement | [Chatbot](/fr/daily/chatbot) |
| **Applications API** | Connecter un outil externe | [API](/fr/developers/api) |
| **Notifications** | Être alerté d'un incident | [Notifications](/fr/daily/notifications) |

::u-alert{color="info" icon="i-lucide-layers"}
Le menu s'adapte à votre plan et à vos droits : une entrée peut être absente si
votre plan ne l'inclut pas (chatbot et API sur Starter, par exemple). Voir
[Plans et quotas](/fr/billing/plans).
::

## Le cycle normal d'utilisation

```
Importer des contacts  →  Écrire un modèle  →  Créer une campagne  →  Suivre les réponses
```

Les trois premières étapes se font une fois ; la quatrième est le quotidien :
surveiller les retours, répondre, relancer.
