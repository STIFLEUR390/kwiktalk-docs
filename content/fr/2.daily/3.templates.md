Un **modèle** est un message enregistré que vous réutilisez dans vos campagnes et
vos envois individuels. KwikTalk en crée quelques-uns automatiquement à
l'inscription ; vous pouvez les modifier ou en ajouter.

Accès : menu de gauche → **Modèles de messages**

## Créer un modèle

1. **Modèles de messages → Ajouter un template**.
2. Choisissez le **type** : **Texte**, **Image** ou **Document (PDF)**.
3. Nommez-le (nom interne : « Bienvenue », « Relance panier »).
4. Rédigez le **contenu**.
5. Pour une image ou un PDF, téléchargez le fichier (10 Mo maximum) et ajoutez
   une **légende** si besoin.
6. Réglez le **statut** sur **Actif** et validez.

::u-alert{color="warning" icon="i-lucide-eye-off"}
Un modèle en **Brouillon** ou **Inactif** n'apparaît pas dans les listes de
sélection au moment de créer une campagne. Si vous ne trouvez pas votre modèle,
c'est presque toujours le statut.
::

## Les variables

Deux variables sont disponibles, à écrire exactement comme ceci :

| Variable | Remplacée par | Exemple |
|---|---|---|
| `{name}` | Le nom du contact | Jean Dupont |
| `{phone}` | Le numéro du contact | +2250701020304 |

Exemple de contenu :

```
Bonjour {name}, votre commande est prête.
Une question ? Répondez à ce message.
```

::u-alert{color="info" icon="i-lucide-case-sensitive"}
Les variables sont **sensibles à la casse** : `{Name}` ou `{nom}` ne sont pas
remplacés et partiront tels quels dans le message.
::

::u-alert{color="info" icon="i-lucide-user-x"}
Quand le destinataire n'est pas un contact enregistré (import Excel ponctuel d'une
campagne), la variable `{name}` reste vide. Testez le rendu avant d'envoyer.
::

## Image et PDF

- **Image** : PNG, JPG ou GIF, 10 Mo maximum.
- **Document** : PDF, 10 Mo maximum.
- La **légende** accompagne le média. Vous pouvez aussi y placer des variables.

## Catégories et filtres

Le champ **catégorie** est libre (« Bienvenue », « Relance »…). Il sert uniquement
à filtrer la liste quand vous en avez beaucoup. La liste se filtre aussi par
statut et par recherche sur le nom.

## Réutiliser un modèle

- Dans une **campagne** : le modèle est obligatoire, il fournit le contenu envoyé.
- Dans un **message individuel** : vous pouvez écrire un texte libre ou partir
  d'un modèle.

Modifier un modèle **ne change pas** les campagnes déjà envoyées : le contenu est
copié au moment de l'envoi.

## Combien de modèles

Le nombre de modèles dépend de votre plan : 5 sur Starter, 50 sur Growth,
illimité sur Business. Voir [Plans et quotas](/fr/billing/plans).
