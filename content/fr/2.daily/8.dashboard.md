Le **tableau de bord** est le premier écran après la connexion. Il répond à une
question : est-ce que tout fonctionne ?

Accès : menu de gauche → **Tableau de bord**

## Ce que montre le tableau de bord

| Bloc | Contenu |
|---|---|
| **Instances WhatsApp** | Combien sont connectées, combien sont bannies |
| **Contacts** | Nombre total et nombre validés sur WhatsApp |
| **Groupes de contacts** | Groupes créés |
| **Modèles de messages** | Combien sont actifs |
| **Tendance des envois** | Messages envoyés sur les 7 derniers jours |
| **Pour commencer** | La liste des étapes restantes pour votre première campagne |
| **Actions rapides** | Raccourcis vers les contacts, les utilisateurs, les rôles |

::u-alert{color="warning" icon="i-lucide-gauge"}
**Une instance « bannie » ou « déconnectée » arrête net vos envois.** C'est la
première chose à regarder quand une campagne ne part pas. Voir
[Dépannage](/fr/help/troubleshooting).
::

## La checklist « Pour commencer »

Quatre étapes, cochées au fur et à mesure :

1. **Connecter votre WhatsApp** — créer une instance et scanner le QR code ;
2. **Ajouter des contacts** — import ou saisie manuelle ;
3. **Créer un modèle de message** ;
4. **Envoyer une campagne**.

Tant qu'une étape reste ouverte, elle est le meilleur endroit où cliquer.

## Statistiques détaillées

La page **Statistiques** approfondit les chiffres sur une période (7, 30 jours…) :

- **Messages entrants**, **premières réponses** et **taux de réponse** — la
  mesure la plus utile : un faible taux de réponse signale un message mal ciblé
  ou trop commercial.
- **Tendances quotidiennes** : entrants et contacts uniques actifs.
- **Campagnes les plus performantes**, comparées à la précédente et à la moyenne
  des campagnes similaires.
- **Performance par instance**, **par modèle** et **par groupe de contacts** :
  envoyés, livrés, échecs, entrants, taux.
- **Types de messages entrants** : texte, image, audio, document…

Les chiffres se rafraîchissent automatiquement, et un bouton **Actualiser**
force la mise à jour.

::u-alert{color="info" icon="i-lucide-database"}
Certains indicateurs avancés dépendent de l'entrepôt analytique. Si une section
affiche « statistiques indisponibles », les agrégats de base restent affichés :
ce n'est pas une erreur de votre compte.
::

## Comment lire vos chiffres

| Indicateur | Bon signe | Signe d'alerte |
|---|---|---|
| Taux de réponse | > 10 % | < 2 % : message trop commercial ou mauvaise liste |
| Échecs d'envoi | < 2 % | > 5 % : numéros invalides, instance instable |
| Contacts validés | proche du total | beaucoup d'invalides : base de mauvaise qualité |
