Tout ce qui arrive sur vos numéros WhatsApp est conservé ici : réponses à une
campagne, questions, images, vocal. C'est votre boîte de réception.

Accès : menu de gauche → **Messages WhatsApp**

## La liste

Chaque ligne affiche le type, le contenu (ou « (Média) »), l'expéditeur, la date,
la **direction** (entrant ou sortant) et le statut.

Les filtres permettent de retrouver un message par :

- **type** — texte, image, audio, document, vidéo, position, contact ;
- **direction** — entrants ou sortants ;
- **statut** — reçu, envoyé, livré, lu, échoué ;
- **recherche** libre sur le contenu ou l'expéditeur.

## La fiche d'un message

Elle contient :

- le **contenu** complet, ou le média avec un bouton **Voir le média** ;
- l'**expéditeur** : nom et numéro, et le **contact lié** s'il est enregistré
  dans votre base ;
- l'**instance WhatsApp** qui a reçu le message ;
- les **horodatages** : reçu, envoyé, livré, lu ;
- le détail technique, réservé au support.

::u-alert{color="info" icon="i-lucide-archive"}
Les médias reçus sont archivés sur nos serveurs. Quand un média n'a pas pu être
archivé, le lien pointe vers les serveurs de WhatsApp et **expire** : ouvrez-le
rapidement ou demandez une copie au support.
::

## Ce qu'il n'y a pas (encore)

Cette page est un **historique**, pas une messagerie de discussion : vous ne
répondez pas depuis la conversation. Pour répondre à un client, utilisez un
[message individuel](/fr/daily/messages) vers son numéro, ou laissez le
[chatbot](/fr/daily/chatbot) répondre automatiquement.

## Traiter les réponses

Un rythme de travail simple :

1. Filtrez sur la période du jour.
2. Ouvrez les messages entrants qui posent une question.
3. Répondez en message individuel, ou notez la demande pour la traiter ailleurs.
4. S'il s'agit d'un « stop » ou d'une demande de désinscription, retirez le
   contact de vos groupes : insister fait signaler votre numéro.
