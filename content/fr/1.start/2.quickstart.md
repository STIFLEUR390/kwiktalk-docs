Ce parcours vous amène du formulaire d'inscription à votre premier message
envoyé. Comptez **une dizaine de minutes**, dont l'essentiel sur le téléphone
pour scanner le QR code.

## Les cinq étapes

| # | Étape | Page détaillée |
|---|---|---|
| 1 | Créer votre compte et confirmer votre e-mail | [Créer un compte](/fr/start/create-account) |
| 2 | Connecter votre numéro WhatsApp | [Connecter votre numéro](/fr/start/connect-whatsapp) |
| 3 | Vérifier le message que KwikTalk a préparé pour vous | [Modèles de messages](/fr/daily/templates) |
| 4 | Envoyer un message de test à votre propre numéro | ci-dessous |
| 5 | Importer vos contacts puis lancer une campagne | [Importer vos contacts](/fr/start/import-contacts) · [Première campagne](/fr/start/first-campaign) |

::u-alert{color="info" icon="i-lucide-wand-2"}
Les étapes 2 à 4 se déroulent dans un **assistant de démarrage** que KwikTalk
ouvre automatiquement tant que votre compte n'est pas configuré. Vous pouvez le
quitter et y revenir plus tard : il reprend là où vous l'avez laissé.
::

## Étape 1 — Créer votre compte

1. Ouvrez la page d'inscription et renseignez votre **nom**, votre **adresse
   e-mail** et un **mot de passe** (à confirmer).
2. Ouvrez l'e-mail de confirmation que KwikTalk vous envoie et cliquez sur le
   lien.
3. Connectez-vous : vous arrivez sur le **tableau de bord**.

Détails, cas de l'e-mail perdu et connexion via votre organisation :
[Créer un compte](/fr/start/create-account).

## Étape 2 — Connecter WhatsApp

1. Dans l'assistant, indiquez le **nom de l'appareil** (par exemple
   « Boutique Akwa ») et votre **numéro WhatsApp**.
2. KwikTalk affiche un **QR code** et un **code d'appairage**.
3. Sur votre téléphone : **WhatsApp → Paramètres → Appareils connectés →
   Associer un appareil**, puis scannez le QR code — ou saisissez le code
   d'appairage à 8 caractères.
4. Le statut passe à **Connecté**. Cliquez sur **Continuer**.

Si le QR code expire : **Régénérer les codes**, ou **Vérifier la connexion**.
Détails : [Connecter votre numéro](/fr/start/connect-whatsapp).

## Étape 3 — Choisir votre message

KwikTalk crée **automatiquement quelques modèles de messages** dès la création de
votre compte. Choisissez celui qui correspond à votre activité, personnalisez la
**salutation** et le **nom de votre entreprise**, puis vérifiez l'aperçu.

Vous pourrez créer les vôtres plus tard : [Modèles de messages](/fr/daily/templates).

## Étape 4 — Envoyer le message test

1. Saisissez le **numéro destinataire** (le vôtre, en format international).
2. Cliquez sur **Envoyer le message test**.
3. Vérifiez sur votre téléphone que le message arrive.

::u-alert{color="success" icon="i-lucide-check-check"}
Ce test prouve une chose : KwikTalk parle bien à WhatsApp avec votre numéro. Si
le message n'arrive pas alors que le statut affiche « Connecté », allez voir
[Dépannage](/fr/help/troubleshooting).
::

## Étape 5 — Vos contacts, puis votre première campagne

1. **Contacts → Importer** : déposez votre fichier Excel (colonnes `name` et
   `phone_number`). Voir [Importer vos contacts](/fr/start/import-contacts).
2. **Campagnes → Créer** : choisissez l'instance, le modèle, les groupes de
   contacts, réglez le délai entre messages, puis démarrez. Voir
   [Envoyer votre première campagne](/fr/start/first-campaign).

::u-alert{color="warning" icon="i-lucide-shield-alert"}
N'envoyez pas 500 messages à des inconnus le premier jour. WhatsApp suspend les
numéros qui envoient trop, trop vite. Lisez
[Éviter le bannissement](/fr/help/anti-ban) **avant** votre première grosse
campagne.
::
