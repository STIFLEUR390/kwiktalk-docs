## Créer un compte

1. Ouvrez la page d'inscription du site KwikTalk et cliquez sur **Créer un
   compte**.
2. Renseignez :
   - votre **nom complet** ;
   - votre **adresse e-mail** ;
   - un **mot de passe**, puis sa **confirmation**.
3. Cliquez sur **Créer mon compte**.

### Confirmer votre adresse e-mail

KwikTalk envoie immédiatement un e-mail de confirmation. **Tant que vous n'avez
pas cliqué sur le lien qu'il contient, l'accès au tableau de bord reste fermé.**

::u-alert{color="info" icon="i-lucide-mail"}
Rien reçu ? Vérifiez le dossier spam, puis utilisez le bouton de **renvoi de
l'e-mail de confirmation** affiché sur la page de vérification.
::

## Se connecter

Sur la page de connexion, deux possibilités :

- **Adresse e-mail + mot de passe** — le cas normal. Le lien « Mot de passe
  oublié ? » permet de définir un nouveau mot de passe par e-mail.
- **Connexion via votre organisation** — si votre entreprise utilise un
  fournisseur d'identité (bouton **Se connecter avec Authentik** ou **Se
  connecter avec Keycloak**), vous êtes redirigé vers sa page de connexion puis
  renvoyé sur KwikTalk. Créez le compte une seule fois de cette façon, sans mot
  de passe KwikTalk.

::u-alert{color="info" icon="i-lucide-key-round"}
Si la **double authentification** est activée sur votre compte, une seconde étape
vous demande un code à 6 chiffres après votre mot de passe.
::

## Que se passe-t-il juste après l'inscription

KwikTalk ouvre un **assistant de démarrage** (`/onboarding`) tant que votre
compte n'est pas configuré : connecter WhatsApp, choisir un modèle, envoyer un
message test. Tant que vous ne l'avez pas terminé, chaque connexion vous y
ramène. Suivez le [parcours express](/fr/start/quickstart).

## Mot de passe oublié

1. Sur la page de connexion, cliquez sur **Mot de passe oublié ?**
2. Saisissez votre adresse e-mail et validez.
3. Ouvrez le lien reçu (il expire), choisissez un **nouveau mot de passe**, puis
   confirmez.

Si vous vous connectez via Authentik ou Keycloak, le mot de passe se réinitialise
chez votre fournisseur d'identité, pas dans KwikTalk.

## Changer de langue

Le sélecteur de langue de l'interface bascule entre **français** et **anglais**.
Votre choix est conservé sur votre compte.
