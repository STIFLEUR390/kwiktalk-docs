Les termes que vous croiserez dans l'interface et dans cette documentation.

## Les objets

**Instance WhatsApp**
Un numéro WhatsApp branché sur KwikTalk. Contacts, campagnes et messages sont
rattachés à une instance. Vous pouvez en avoir plusieurs.

**Contact**
Un nom et un numéro de téléphone enregistrés dans KwikTalk.

**Groupe de contacts**
Un ensemble nommé de contacts (« Clients Abidjan », « Prospects salon 2026 »).
C'est un groupe que vous ciblez lors d'une campagne.

**Modèle de message** (aussi appelé *template*)
Un message enregistré et réutilisable, avec des variables, éventuellement
accompagné d'une image ou d'un document. Vous le choisissez au moment de créer
une campagne.

**Campagne**
Un envoi d'un même modèle à un ensemble de contacts, avec un délai entre chaque
message, immédiat ou planifié.

**Message individuel**
Un envoi à un seul destinataire, sans passer par une campagne.

## Les états

**En attente** (contact)
Importé mais pas encore vérifié.

**Validé** (contact)
Le numéro a été vérifié : il existe bien sur WhatsApp.

**Invalide** (contact)
Le numéro n'existe pas sur WhatsApp. Inutile de lui écrire : le message échouera.

**Connecté / Déconnecté** (instance)
L'instance parle correctement à WhatsApp, ou le lien est rompu (téléphone
réinitialisé, appareil retiré, suspension).

**Envoyé / Délivré / Lu** (message)
*Envoyé* : KwikTalk a transmis le message à WhatsApp. *Délivré* : il est arrivé
sur le téléphone du destinataire. *Lu* : le destinataire l'a ouvert.

**Brouillon / Planifiée / En cours / En pause / Terminée** (campagne)
Les étapes de vie d'une campagne.

## Les réglages

**Délai entre messages**
Le temps d'attente que KwikTalk respecte entre deux envois d'une même campagne
(3 à 10 secondes). Un délai court fait finir la campagne plus vite mais augmente
le risque de suspension.

**Planification**
Le fait de choisir une date et une heure de démarrage. L'heure est lue dans le
**fuseau horaire** que vous sélectionnez.

**Quota**
Le nombre maximum d'objets autorisés par votre plan : instances, contacts,
campagnes, modèles, applications API. Voir [Plans et quotas](/fr/billing/plans).

**Portefeuille**
Votre solde prépayé dans KwikTalk, utilisé pour payer l'abonnement et les
recharges. Il est distinct de l'**abonnement**, qui est votre plan.

## Côté WhatsApp

**Multi-appareil**
Le mode de WhatsApp Web : un appareil lié peut envoyer des messages même si le
téléphone est éteint.

**QR code**
Le code à scanner depuis WhatsApp pour lier un appareil. Il expire : il faut le
régénérer.

**Code d'appairage**
Une alternative au QR code : un code à 8 caractères à saisir dans WhatsApp pour
lier l'appareil.

**Bannissement**
La suspension d'un numéro par WhatsApp, généralement pour envoi massif ou pour
plaintes des destinataires. Voir
[Éviter le bannissement](/fr/help/anti-ban).
