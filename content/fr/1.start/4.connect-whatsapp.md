Une **instance** représente un numéro WhatsApp branché sur KwikTalk. C'est elle
qui envoie les messages ; contacts, modèles et campagnes s'appuient dessus.

Accès : menu de gauche → **WhatsApp**

## Ce qu'il faut avant de commencer

- Un **numéro WhatsApp actif**, dont vous avez le téléphone en main.
- Un créneau de 5 minutes : le QR code expire vite.
- Un plan autorisant assez d'instances (1 sur Starter, 5 sur Growth, illimité
  sur Business — voir [Plans et quotas](/fr/billing/plans)).

## Créer l'instance

1. Cliquez sur **Créer une instance**.
2. Renseignez le **nom de l'instance** — choisissez un nom parlant, il apparaît
   partout dans l'interface (« Boutique Akwa », « Support », « Commercial 1 »).
3. Renseignez le **numéro de téléphone** au format international.
4. Validez.

::u-alert{color="info" icon="i-lucide-link"}
Le champ **URL du webhook** est réservé aux installations techniques. Si vous ne
savez pas quoi y mettre, laissez-le vide : KwikTalk fonctionne entièrement sans.
::

## Associer le téléphone

Sur la page de l'instance, deux méthodes sont proposées en même temps. Choisissez
celle qui vous arrange.

### Méthode A — QR code

1. Cliquez sur **Générer les codes de connexion** (l'instance doit être
   **Non connectée** au départ).
2. Sur le téléphone : **WhatsApp → Paramètres → Appareils connectés → Associer un
   appareil**.
3. Scannez le QR code affiché par KwikTalk.

### Méthode B — Code d'appairage

Utile si vous ne pouvez pas scanner (téléphone tenu à distance, écran partagé) :

1. Sur le téléphone : **WhatsApp → Paramètres → Appareils connectés → Associer
   avec un numéro**.
2. Saisissez le **code d'appairage** affiché par KwikTalk.

Dans les deux cas, le statut de l'instance passe à **Connecté** en quelques
secondes. KwikTalk vérifie la connexion automatiquement.

## Si la connexion ne s'établit pas

| Symptôme | Ce qu'il faut faire |
|---|---|
| Le QR code a expiré | Cliquez sur **Régénérer les codes** |
| Le scan a réussi mais le statut reste « Non connectée » | Cliquez sur **Vérifier la connexion** |
| L'appairage a échoué, rien ne marche | Cliquez sur **Repartir de zéro** : l'appareil lié est supprimé côté WhatsApp et vous pouvez rescanner |
| Le numéro était déjà lié à un autre outil | Retirez d'abord l'ancien appareil lié dans WhatsApp, puis recommencez |

## Garder la connexion

- Le lien est un lien **multi-appareil** : votre téléphone peut être éteint,
  WhatsApp Web continue de fonctionner.
- Ne supprimez jamais l'appareil « KwikTalk » depuis les appareils connectés de
  WhatsApp : cela coupe l'envoi des campagnes.
- Si WhatsApp déconnecte le compte (changement de téléphone, réinstallation),
  le statut passe à **Déconnecté** et une notification vous prévient. Il faut
  rescaner un QR code.

## Gérer plusieurs numéros

Chaque instance est indépendante : contacts, campagnes et messages y sont
rattachés. Une campagne choisit **une seule** instance d'envoi.
