## Inscription

1. Rendez-vous sur la page d'inscription de KwikTalk.
2. Renseignez votre nom, votre adresse e-mail et un mot de passe.
3. Validez.

::u-alert{type="info" icon="i-lucide-mail"}
La connexion se fait par le middleware `verified` : **votre adresse e-mail doit être
vérifiée** avant d'accéder au tableau de bord. Un e-mail de vérification vous est
envoyé immédiatement après l'inscription.
::

Si vous n'avez pas cliqué sur le lien, vous pouvez renvoyer l'e-mail depuis la page
de vérification, ou demander une réinitialisation depuis
**« Mot de passe oublié »**.

## Connexion

La page de connexion accepte :

- **e-mail + mot de passe**
- **Authentik (OIDC)** — si votre organisation a activé la connexion fédérée, un
  bouton vous redirige vers Authentik, puis un callback ramène l'utilisateur
  authentifié.

::u-alert{type="warning" icon="i-lucide-key-round"}
KwikTalk supporte la **double authentification (2FA)**. Si elle est activée sur
votre compte, la connexion demande en plus un code à usage unique.
::

## Ce qui vous attend au premier accès

À la connexion, un **parcours d'onboarding** vous guide, dans cet ordre :

| Étape | Objectif |
|---|---|
| `welcome` | Accueil et présentation du parcours |
| `whatsapp` | Connecter votre première instance WhatsApp (QR code) |
| `templates` | Choisir ou créer un modèle de message |
| `personalize` | Personnaliser le contenu |
| `test` | Envoyer un message test |

Vous pouvez le reprendre à tout moment depuis **`/onboarding`**.
Voir [Premiers pas](/fr/overview/first-steps).

## Préférences de langue

L'interface et les pages publiques sont **bilingues français / anglais**. La
langue se change depuis le sélecteur de l'en-tête ; votre choix est mémorisé.
