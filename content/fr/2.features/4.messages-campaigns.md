Deux niveaux d'envoi :

- **[Envoyer un message](#envoyer-un-message)** — un ou quelques destinataires, à la main.
- **[Campagnes](#campagnes)** — un grand nombre de destinataires, avec lot, délai et planification.

Accès : **`/admin/messages`** et **`/admin/message-campaigns`**

## Envoyer un message

1. Allez dans **Messages → Envoyer**.
2. Choisissez l'**instance** d'envoi.
3. Saisissez le ou les **destinataires** (numéros ou contacts).
4. Rédigez le contenu ou choisissez un **modèle**.
5. Envoyez.

Le message est créé avec le statut `sending`, puis suit son cycle de vie.

### Statuts d'un message

| Statut | Signification |
|---|---|
| `pending` | En file d'attente |
| `sending` | En cours d'envoi |
| `sent` | Remis au serveur WhatsApp |
| `delivered` | Livré sur l'appareil du destinataire |
| `read` | Lu |
| `failed` | Échec |

::u-alert{type="info" icon="i-lucide-eye"}
Les transitions `sent → delivered → read` remontent en **temps réel** (Reverb).
Pour les suivre aussi en dehors de l'interface, branchez un
[webhook `message.status.updated`](/fr/integrations/webhooks).
::

## Campagnes

Une campagne regroupe l'envoi d'un **modèle** vers une **sélection de contacts**.

### Créer une campagne

1. **Campagnes → Créer**.
2. Nommez-la et décrivez-la.
3. Choisissez le **modèle de message** à envoyer.
4. Définissez la **cible** :
   - un ou plusieurs **groupes de contacts**, ou
   - un **fichier Excel** importé directement dans la campagne.
5. Configurez l'envoi (voir ci-dessous).
6. Enregistrez.

### Configurer l'envoi

| Réglage | Rôle |
|---|---|
| **Taille de lot** (`batch_size`) | Nombre de messages envoyés d'affilée |
| **Délai entre lots** (`batch_delay_seconds`) | Pause, en secondes, entre deux lots |
| **Tentatives max** (`max_retries`) | Reprises automatiques par message en cas d'échec |
| **Planification** (`scheduled_for`) | Date et heure de démarrage |
| **Fuseau** | Fuseau horaire propre à la campagne : l'heure planifiée est interprétée dans **ce** fuseau |

::u-alert{color="warning" icon="i-lucide-timer"}
Le **délai entre lots** est votre premier allié contre le bannissement. Un délai
trop court sur une grosse liste est la cause n°1 de numéro suspendu. Voir
[Protection anti-spam](/fr/resources/anti-spam).
::

### Cycle de vie

Une campagne passe par les statuts suivants :

```
draft ─→ scheduled ─→ running ─→ completed
              │           │
              └─────→ paused ──→ running
                                    │
                                 failed
```

| Action | Effet |
|---|---|
| **Démarrer** | Passe la campagne en `running` |
| **Mettre en pause** | Interrompt proprement, l'état est conservé |
| **Reprendre** | Repart là où elle s'est arrêtée |
| **Supprimer** | Détruit la campagne |

Le démarrage automatique des campagnes `scheduled` est géré par le planificateur
Laravel à l'heure `scheduled_for`.

### Suivi

Une campagne expose ses compteurs en direct :

- `messages_sent`
- `messages_delivered`
- `messages_failed`
- `messages_pending`

La fiche de campagne détaille chaque **destinataire** individuellement
(`message_campaign_recipients`), avec son statut propre et les contacts
**ignorés** (`skipped_contacts`).

::u-alert{color="info" icon="i-lucide-pause-circle"}
Si la **protection anti-ban** déclenche une pause automatique, la campagne passe
en `paused` et la raison est enregistrée
(`anti_ban_pause_reason`, `anti_ban_paused_at`). Elle reprend d'elle-même quand le
numéro est de nouveau utilisable.
::

### Quotas

| Plan | Campagnes simultanées |
|---|:---:|
| Starter | 2 |
| Growth | 20 |
| Business | ∞ |

## Cas particuliers

- **Contacts ignorés** — un contact déjà traité ou invalidé peut être exclu de la
  campagne ; il apparaît dans `skipped_contacts`.
- **Échec définitif** — les messages en échec définitif se retrouvent dans la
  **DLQ de l'instance**, rejouables un par un
  (voir [Instances WhatsApp](/fr/features/whatsapp-instances)).
