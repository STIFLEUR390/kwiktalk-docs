## Connexion et compte

| Symptôme | Cause probable | Que faire |
|---|---|---|
| « Votre e-mail n'est pas vérifié » | Le lien de confirmation n'a pas été cliqué | Ouvrez l'e-mail de KwikTalk, ou renvoyez-le depuis la page de vérification |
| Mot de passe refusé | Mot de passe incorrect, ou compte créé via Authentik/Keycloak | Utilisez **Mot de passe oublié ?** ; si vous passez par votre organisation, réinitialisez chez elle |
| Connexion en boucle sur l'assistant de démarrage | L'assistant n'est pas terminé | Terminez la connexion WhatsApp et le message test, ou utilisez la sortie de secours vers le tableau de bord |
| Code 2FA refusé | L'horloge du téléphone dérive | Activez l'heure automatique dans les réglages du téléphone, puis réessayez |

## WhatsApp et instances

| Symptôme | Cause probable | Que faire |
|---|---|---|
| Le QR code ne s'affiche pas | L'instance est déjà connectée | Le statut doit être **Non connectée** avant de générer un code |
| Le QR code expire avant le scan | Trop de temps écoulé | **Régénérer les codes** |
| Le scan réussit, le statut reste « Non connectée » | La vérification n'a pas eu lieu | **Vérifier la connexion** |
| Impossible de lier le numéro | Un ancien appareil KwikTalk est encore lié | Dans WhatsApp → Appareils connectés, retirez l'ancien appareil, puis **Repartir de zéro** |
| Statut « Déconnecté » sans raison | Téléphone réinitialisé, WhatsApp réinstallé, appareil retiré | Reconnectez l'instance |
| Statut « Banni » | WhatsApp a suspendu le numéro | Voir [Éviter le bannissement](/fr/help/anti-ban) — n'essayez pas de reconnecter en boucle |

## Campagnes et messages

| Symptôme | Cause probable | Que faire |
|---|---|---|
| La campagne ne démarre pas | Instance non connectée, ou plan sans modèle actif | Vérifiez le statut de l'instance, puis le statut du modèle |
| La campagne est « En pause » | Le système anti-ban a freiné l'envoi | Lisez le motif affiché sur la campagne avant de reprendre |
| Beaucoup d'échecs | Numéros invalides ou non validés | [Validez vos contacts](/fr/daily/contacts) |
| Message envoyé mais jamais « Délivré » | Destinataire hors ligne, ou numéro sans WhatsApp actif | Vérifiez le numéro avec la validation |
| Les images ne partent pas | Fichier trop lourd | Restez sous 10 Mo pour les modèles |
| Rien n'arrive chez personne | Le message est bloqué côté WhatsApp | Réduisez le rythme, relisez le [guide anti-ban](/fr/help/anti-ban) |
| Variables `{name}` non remplacées | Contact non enregistré, ou variable mal écrite | Vérifiez la casse : `{name}` et non `{Name}` |

## Contacts

| Symptôme | Cause probable | Que faire |
|---|---|---|
| L'import Excel est refusé | En-têtes absents ou mal orthographiés | Les colonnes doivent s'appeler exactement `name` et `phone_number` |
| Le nombre de contacts importés est inférieur au fichier | Doublons ignorés | C'est normal : les numéros déjà présents ne sont pas dupliqués |
| La validation échoue en masse | Numéros sans WhatsApp, ou instance déconnectée | Vérifiez l'instance, puis validez par lots plus petits |

## Limites et facturation

| Symptôme | Cause probable | Que faire |
|---|---|---|
| « Limite atteinte » à la création | Quota du plan épuisé | Supprimez des objets inutiles ou changez de plan — voir [Plans et quotas](/fr/billing/plans) |
| Paiement refusé | Plafond de carte, paiement international bloqué, solde insuffisant | Changez de moyen de paiement, ou rechargez le [portefeuille](/fr/billing/wallet) |
| Abonnement « En attente de paiement » | Le paiement n'a pas été confirmé | Utilisez **Reprendre le paiement** |
| Les factures de ce mois manquent | Le paiement n'est pas encore confirmé | Elles apparaissent une fois le paiement validé |

## API

| Erreur | Cause |
|---|---|
| `401 missing_api_key` | L'en-tête `Authorization: Bearer <clé>` est absent |
| `401 invalid_api_key` | La clé est fausse, ou a été régénérée |
| `403 inactive_api_key` | L'application API est désactivée |
| `403 instance_disconnected` | L'instance liée à la clé n'est plus connectée |
| `429` | Limite de débit atteinte (requêtes par minute) |

## Vous ne trouvez pas votre cas

Contactez le support depuis le site KwikTalk en précisant : l'**instance**
concernée, l'**heure** approximative du problème, et le **message d'erreur**
affiché. Une capture d'écran accélère beaucoup le diagnostic.
