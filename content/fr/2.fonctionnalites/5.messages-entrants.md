Tous les messages **reçus** sur vos instances sont centralisés ici : réponses aux
campagnes, questions, accusés de lecture en texte libre…

Accès : **`/admin/incoming-messages`**

::u-alert{type="info" icon="i-lucide-inbox"}
Le rôle `user` dispose des permissions `view incoming messages` et
`manage incoming messages` : le suivi des conversations fait partie de l'espace
de travail standard, sans passer par l'administration.
::

## Ce qui est capturé

Chaque message entrant conserve :

| Champ | Contenu |
|---|---|
| `content` | Corps du texte |
| `message_type` | Type : texte, image, document, audio… |
| `from_me` | Si le message vient de votre propre numéro |
| `media_url` | Pièce jointe reçue (avec `media_filename`, `media_mimetype`, `media_caption`) |
| `chat_jid` | Identifiant de la discussion WhatsApp |
| `contact_id` | Contact associé, si identifié |
| `evolution_message_id` | Identifiant côté Evolution API |
| `delivered` / `delivered_at` | Prise en compte par KwikTalk |
| `failed` / `error_message` | Si le traitement a échoué |

## Lister et consulter

La liste permet de filtrer ; la fiche détaille un message et son contexte.

- **`/admin/incoming-messages`** — la liste.
- **`/admin/incoming-messages/{id}`** — le détail.

## Relier à un contact

Lorsque l'expéditeur correspond à un numéro de votre base, le message est lié au
**contact** (`contact_id`) et apparaît dans son historique. Sinon, vous pouvez
créer le contact à partir du numéro.

::u-alert{color="warning" icon="i-lucide-message-circle-warning"}
C'est précisément pour cela qu'on **valide les numéros** avant campagne :
plus votre base est à jour, plus les réponses entrantes sont automatiquement
rattachées au bon interlocuteur. Voir
[Contacts et groupes](/fr/fonctionnalites/contacts-et-groupes).
::

## Répondre

Depuis la fiche, vous pouvez répondre au contact sur l'instance correspondante.
La réponse suit le même cycle de statut qu'un message sortant.

## Automatiser les réponses

Les messages entrants sont le **déclencheur** du [chatbot](/fr/fonctionnalites/chatbot)
et sont exposés aux intégrations par le webhook `message.received`.

Pour récupérer les messages entrants **depuis une application externe**, utilisez
l'endpoint API `GET /api/v1/messages` — voir
[Applications API](/fr/integrations/applications-api).
