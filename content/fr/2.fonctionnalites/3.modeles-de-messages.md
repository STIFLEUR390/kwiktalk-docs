Un **modèle** est un message enregistré, réutilisable pour les envois unitaires et
pour les campagnes.

Accès : **`/admin/message-templates`**

::u-alert{type="info" icon="i-lucide-layers"}
Le modèle s'applique à la fois au **contenu texte** et à la **légende des médias**
(`media_caption`) : une seule personnalisation couvre les deux.
::

## Créer un modèle

1. **Modèles → Créer**.
2. Nommez-le (interne, sert à le retrouver).
3. Choisissez le **type** : texte simple, image, document…
4. Rédigez le contenu, en insérant des variables si besoin.
5. Enregistrez.

Les champs médias (`media_url`, `media_filename`, `media_mimetype`,
`media_caption`) sont renseignés lorsque le modèle contient une pièce jointe.

## Les variables

Seules **deux variables** sont prises en charge aujourd'hui :

| Variable | Remplace par |
|---|---|
| `{name}` | Le nom du contact |
| `{phone}` | Le numéro de téléphone du contact |

::u-alert{color="warning" icon="i-lucide-case-sensitive"}
Les variables sont **sensibles à la casse** : `{Name}` ne sera **pas** remplacé.
Seuls `{name}` et `{phone}` fonctionnent — toute autre accolade reste littérale
dans le message envoyé.
::

Comportement précis :

- **Toutes** les occurrences sont remplacées.
- Si la donnée du contact est absente, la variable est remplacée par une
  **chaîne vide** (le message ne contient donc pas `{name}`).
- Les valeurs sont **échappées** : l'éditeur produit du HTML, et l'échappement
  évite de casser le balisage avant la conversion WhatsApp.

### Exemple

```
Bonjour {name}, votre commande est prête.
Nous vous joignons au {phone}.
```

Résultat pour « Awa » au `+225 07…` :

```
Bonjour Awa, votre commande est prête.
Nous vous joignons au +225 07….
```

## Utiliser un modèle

- **Envoi unitaire** : depuis [Messages](/fr/fonctionnalites/messages-et-campagnes),
  choisissez le modèle, puis les destinataires.
- **Campagne** : le modèle est sélectionné à la création de la campagne.
- **Onboarding** : le parcours de premier usage vous propose de choisir et
  personnaliser un modèle.

## Quotas et organisation

| Plan | Modèles |
|---|:---:|
| Starter | 5 |
| Growth | 50 |
| Business | ∞ |

Chaque modèle dispose d'un **statut** (`status`) et d'un indicateur `active` :
vous pouvez garder un modèle prêt sans l'exposer dans les sélecteurs.

## Suppression

- **Un modèle** — depuis sa fiche.
- **Tous les modèles** — action groupée depuis la liste.

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
La suppression en masse est **définitive**, et les campagnes en cours qui
référencent un modèle supprimé ne pourront plus le résoudre. Vérifiez l'usage
avant.
::
