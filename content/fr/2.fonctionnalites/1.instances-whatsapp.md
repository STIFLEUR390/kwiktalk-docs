Une **instance** est l'unité centrale de KwikTalk : c'est elle qui porte un numéro
WhatsApp. Contacts, modèles, campagnes et clés API lui sont rattachés.

Accès : **`/admin/whatsapp-instances`**

## Créer une instance

1. Rendez-vous dans **Instances WhatsApp** → **Créer**.
2. Donnez-lui un nom (il apparaîtra partout dans l'interface).
3. L'instance est créée, il reste à la connecter.

## Connecter le numéro

1. Ouvrez l'instance.
2. Un **QR code** s'affiche.
3. Sur le téléphone : **WhatsApp → Appareils liés → Lier un appareil**.
4. Scannez le code.

::u-alert{type="info" icon="i-lucide-qr-code"}
Trois actions sont disponibles si le couplage ne va pas bien :

| Action | Usage |
|---|---|
| **Régénérer le QR code** | Le code a expiré |
| **Réinitialiser l'instance** | Le couplage a échoué ou est dans un état incohérent |
| **Rafraîchir le statut** | Vérifier l'état sans recharger la page |
::

## Suivre l'état

Une instance expose son historique de connexion :

- `last_connected_at` / `last_disconnected_at`
- `reconnect_count` — nombre de reconnexions automatiques
- `banned_at` / `banned_until` / `ban_reason` — si le numéro a été **banni** par
  WhatsApp

::u-alert{color="warning" icon="i-lucide-ban"}
**Un numéro banni** : les envois sont bloqués et les campagnes concernées passent
en pause automatique (`anti_ban_paused_at`). Vous recevez une notification. Les
envois reprennent seuls à la fin du bannissement — voir
[Protection anti-spam](/fr/ressources/anti-spam).
::

## Synchroniser les contacts

Depuis une instance vous pouvez **synchroniser les contacts** : KwikTalk récupère
la liste des contacts présents sur le compte WhatsApp lié et les compare à votre
base. Voir [Contacts et groupes](/fr/fonctionnalites/contacts-et-groupes).

## File d'échec (DLQ)

Une instance dispose d'une **dead letter queue** : les messages dont l'envoi a
échoué de façon définitive y sont collectés, et **chaque entrée peut être rejouée**
individuellement.

C'est le premier réflexe à avoir en cas d'échec d'envoi massif : ouvrir la DLQ de
l'instance, puis rejouer les entrées une fois la cause corrigée.

## Multi-numéros

Le nombre d'instances simultanées dépend de votre plan :

| Plan | Instances |
|---|:---:|
| Starter | 1 |
| Growth | 5 |
| Business | ∞ |
