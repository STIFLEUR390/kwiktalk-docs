L'onboarding se déroule à **`/onboarding`** et se compose de cinq étapes. Il se
reprend là où vous l'avez laissé.

## 1. `welcome` — Accueil

Présentation du parcours. Rien à configurer.

## 2. `whatsapp` — Connecter un numéro

C'est l'étape la plus importante.

1. Créez l'**instance WhatsApp** : donnez-lui un nom reconnaissable
   (« Ventres », « Support », « Commercial 1 »…).
2. Un **QR code** est généré. Ouvrez WhatsApp sur votre téléphone →
   **Appareils liés** → **Lier un appareil** → scannez le code.
3. Patientez jusqu'à ce que le statut passe à **connecté**.

::u-alert{color="warning" icon="i-lucide-qr-code"}
Le QR code expire rapidement. Depuis l'interface vous pouvez :

- **Régénérer le QR code** (`instance.regenerate-qr`) si le code est expiré ;
- **Réinitialiser l'instance** (`instance.reset`) si le couplage a échoué ;
- **Rafraîchir le statut** (`instance.refresh-status`) sans recharger la page.
::

::u-alert{type="info" icon="i-lucide-smartphone"}
L'instance reste connectée en **mode multi-appareil** : votre téléphone peut
rester hors ligne, WhatsApp Web continue de fonctionner.
::

Voir le détail : [Instances WhatsApp](/fr/fonctionnalites/instances-whatsapp).

## 3. `templates` — Choisir un modèle

Sélectionnez un **modèle de message** existant ou créez-en un. Le modèle définit le
corps du message et ses variables.

## 4. `personalize` — Personnaliser

Ajustez le contenu pour votre cas d'usage. Les variables sont renseignées à
l'envoi.

## 5. `test` — Envoyer un message test

Envoyez un message à **votre propre numéro** (ou un numéro de test) pour valider
la chaîne de bout en bout : instance connectée, modèle correct, message livré.

::u-alert{color="success" icon="i-lucide-check-circle"}
Une fois le test reçu, terminez l'onboarding (`complete`). Vous atterrissez sur le
[Tableau de bord](/fr/mon-compte/tableau-de-bord).
::
