KwikTalk est une **plateforme marketing WhatsApp**. Elle permet de piloter un ou
plusieurs numéros WhatsApp, d'importer une base de contacts, d'envoyer des messages
individuels ou des campagnes en lot, et de connecter le tout à vos outils via une
API et des webhooks.

::u-alert{color="info" icon="i-lucide-info"}
KwikTalk fonctionne sur **WhatsApp Web** (mode multi-appareil). Vous scannez un QR
code, votre numéro reste connecté, et les envois partent depuis votre propre compte.
::

## Ce que vous pouvez faire

| Domaine | Fonctionnalité |
|---|---|
| Numéros | Connecter plusieurs **instances WhatsApp** par QR code, suivre leur état en temps réel |
| Base contacts | Importer un fichier **Excel**, valider les numéros, organiser en **groupes** |
| Contenu | Créer des **modèles** avec variables dynamiques |
| Envoi | Messages individuels, **campagnes** en lot avec planification |
| Réponses | Centraliser les **messages entrants**, répondre depuis l'interface |
| Automatisation | **Chatbot** par règles ou workflow, numéros exclus, portée par groupe |
| Intégration | **API REST** versionnée, **webhooks** signés HMAC-SHA256 |
| Sécurité | Protection **anti-ban** avec quotas préventifs et gestion des bannissements |

## Comment c'est organisé

Le produit repose sur un petit nombre d'entités :

```
Instance WhatsApp  ←  rattachée à un compte utilisateur
├── Contacts (+ groupes)
├── Modèles de messages
├── Messages (individuels)
├── Campagnes (envois groupés)
├── Messages entrants (réponses)
├── Application API (clé, rattachée à UNE instance)
└── Webhooks (endpoints d'événements)
```

Une **instance** est l'unité centrale : c'est elle qui porte le numéro WhatsApp.
Contacts, modèles et campagnes lui sont rattachés. Une **clé API** est également
liée à une seule instance — les appels passent donc toujours par le bon numéro.

## Qui accède à quoi

KwikTalk gère les droits par **permission**, pas par menu figé.

::u-alert{color="warning" icon="i-lucide-shield-alert"}
Cette documentation couvre **les pages publiques** (sans compte) et **le rôle
`user`** — l'espace de travail complet d'un utilisateur. Les fonctions
d'administration de la plateforme relèvent des rôles `admin` et `super-admin` et
ne sont pas décrites ici.
::

Le rôle `user` dispose de l'ensemble des fonctionnalités opérationnelles :

- tableau de bord
- gestion des instances WhatsApp
- gestion des contacts et groupes
- gestion des modèles de messages
- envoi et suivi des messages
- création et pilotage des campagnes
- consultation des messages entrants
- gestion des applications API
- gestion du chatbot
- gestion des webhooks
