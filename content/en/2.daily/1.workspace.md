Once your number is connected, everything happens in the left menu. Here is what
each entry contains.

| Menu entry | What you do there | Page |
|---|---|---|
| **Dashboard** | Your account status on one screen | [Dashboard](/en/daily/dashboard) |
| **WhatsApp** | Connect and monitor your numbers | [Connect your number](/en/start/connect-whatsapp) |
| **Contacts** | Add, import, validate your contacts | [Contacts and groups](/en/daily/contacts) |
| **Contact groups** | File contacts by commercial target | [Contacts and groups](/en/daily/contacts) |
| **Message templates** | Write reusable messages | [Message templates](/en/daily/templates) |
| **Messages** | Send to a single recipient | [Single messages](/en/daily/messages) |
| **Message campaigns** | Send to a set of contacts | [Campaigns](/en/daily/campaigns) |
| **WhatsApp messages** | Read what your customers replied | [Incoming messages](/en/daily/inbox) |
| **Chatbot** | Answer automatically | [Chatbot](/en/daily/chatbot) |
| **API applications** | Connect an external tool | [API](/en/developers/api) |
| **Notifications** | Get alerted about an incident | [Notifications](/en/daily/notifications) |

::u-alert{color="info" icon="i-lucide-layers"}
The menu adapts to your plan and your rights: an entry can be missing if your plan
does not include it (chatbot and API on Starter, for example). See
[Plans and quotas](/en/billing/plans).
::

## The normal cycle

```
Import contacts  →  Write a template  →  Create a campaign  →  Follow the replies
```

The first three steps are done once; the fourth is the daily routine: watch the
replies, answer, follow up.
