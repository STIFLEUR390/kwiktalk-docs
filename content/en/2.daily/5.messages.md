A **single message** goes to one recipient only. For a set of contacts, use a
[campaign](/en/daily/campaigns).

Access: left menu → **Messages** → **New message**

## Send

| Field | What it is |
|---|---|
| **Instance** | The number that sends |
| **Recipient** | The number, in international format, **without the `+`** |
| **Type** | Text, Image, Document or Audio |
| **Content** | The message body |
| **Media** | By upload or by URL, depending on the type |
| **Caption** | Optional, for an image or a document |

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
Write the number in international format **without `+`, space or dash**:
`2250701020304`, not `+225 07 01 02 03 04`. With the `+`, the send fails.
::

**Send** hands the message to WhatsApp. The status then evolves: *Pending*,
*Sending*, *Sent*, *Delivered*, *Read* — or *Failed*, with the reason.

## Character limit

A message is limited to **4 096 characters**. Beyond that, split it or move the
content into a PDF document.

## Text, image, document, audio

- **Text** — plain text, line breaks and emoji.
- **Image** — JPEG, PNG or GIF, **10 MB maximum**, with an optional caption.
- **Document** — PDF, DOC, DOCX or TXT (invoice, quote, catalogue), **10 MB
  maximum**.
- **Audio** — a voice message, **10 MB maximum**.

Variables `{name}` and `{phone}` are **not** substituted in a single message: it is
targeted at one person, write their name directly.

## When to use it

- answer a customer who wrote to you outside a campaign;
- send one invoice;
- test a message before putting it into a campaign.
