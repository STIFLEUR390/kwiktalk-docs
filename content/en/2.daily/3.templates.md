A **template** is a saved message that campaigns reuse. Write it once, personalise
it with variables, send it a thousand times.

Access: left menu → **Message templates** → **Create a template**

## Create a template

| Field | What it is |
|---|---|
| **Name** | Internal name, to find it in the list |
| **Type** | Text, Image or Document |
| **Content** | The message body, with `{name}` and `{phone}` if you want |
| **Category** | Free label to sort your templates |
| **Status** | Draft, Active or Inactive |

### Text

Simplest case: only the content. Line breaks are kept, emoji included.

### Image

Add the media by upload or by URL, plus an optional **caption**. Accepted formats
are JPEG, PNG and GIF; **10 MB maximum**.

### Document

For a PDF (catalogue, price list, invoice): upload or URL, plus an optional
caption. **10 MB maximum**.

## Variables

Two variables are available, both optional:

| Variable | Replaced with |
|---|---|
| `{name}` | The contact's name |
| `{phone}` | The contact's number |

```
Hello {name}, your order is ready. Reply to this message for the pickup address.
```

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
Variables are **case-sensitive**: `{name}` works, `{Name}` does not and stays
displayed as typed. No other variable is supported today: keep it to these two.
::

## Status: draft, active, inactive

- **Draft** — the template exists but is not usable: it does **not** appear in the
  campaign template picker.
- **Active** — usable in campaigns and single messages.
- **Inactive** — hidden without being deleted.

So a template must be set to **Active** before your first campaign. It is a
frequent stumbling block on the first try.

## Writing a message that gets read

- **Say who you are in the first line.** A message with no identified sender gets
  reported.
- **One message, one call to action.** "Reply YES" beats a five-question message.
- **Keep it short.** Two or three sentences: WhatsApp is not email.
- **Personalise with `{name}`.** A personalised message is read and reported less.
- **Ask for a reply.** "Reply YES" starts a conversation; a closing "do not
  reply" tells WhatsApp your message is unsolicited.
- **Avoid CAPS, "PROMO!!!", shortened links** (bit.ly and friends): they are
  spam signals.
