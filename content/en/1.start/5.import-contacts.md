A **contact** is a name and a phone number. Contacts are filed in **groups**: a
group is what you target in a campaign.

Access: left menu → **Contacts**

## Fastest path: add one contact by hand

**Contacts → Add contact**: name, number in international format
(`+2250701020304`), groups (optional), then **Create contact**.

Fine for a handful of contacts. Beyond that, use the import.

## Import an Excel file

### 1. Prepare the file

The file must be **`.xlsx` or `.xls`** and contain these columns on the first row:

| Column | Required | Content |
|---|:---:|---|
| `name` | yes | Contact name |
| `phone_number` | yes | Number in international format |
| `groups` | no | Groups to assign (comma-separated) |

::u-alert{color="info" icon="i-lucide-download"}
A template file is downloadable from the import page: start from it if you are
unsure about the headers.
::

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
The `name` and `phone_number` headers must be spelled **exactly** like this. A
file with "Name" and "Phone" columns will be rejected.
::

### 2. Import

1. **Contacts → Import**.
2. Optionally choose a **WhatsApp instance**: it will be used to validate the
   numbers. Without an instance, contacts are imported unvalidated — you can run
   validation later.
3. Optionally choose **groups**: if selected here, all imported contacts are added
   to them and the `groups` column in the file is ignored.
4. Drop the file, then click **Import contacts**.

At the end, KwikTalk reports how many contacts were created and how many already
existed (duplicates are ignored, not duplicated).

## Validate numbers

A contact has one of three statuses:

| Status | Meaning |
|---|---|
| **Pending** | Imported, not verified yet |
| **Validated** | The number exists on WhatsApp |
| **Invalid** | The number does not exist on WhatsApp |

Validation avoids sending — and getting your number reported — to recipients that
do not exist.

1. Tick the relevant contacts (or all).
2. Click **Validate selection**.
3. Wait for the end of the run: each contact's status updates.

::u-alert{color="warning" icon="i-lucide-gauge"}
Validation queries WhatsApp contact by contact. On a large list, run it in batches
of a few hundred, not on 5 000 contacts at once.
::

## Organise into groups

- **Contact groups** (left menu): create a group, give it a name, then add
  contacts to it.
- From the contact list, select several rows then **Sync groups** to add or remove
  several contacts at once.
- A contact can belong to several groups.

A group is the simplest way to say "this campaign goes to my Abidjan customers"
without rebuilding the list each time.

## Good practice

- Import a list that **consented** to receive your messages. A purchased list gets
  the number banned.
- Keep one group per commercial target, not one "everyone" group.
- Validate before the first campaign: you save failed sends.
