The terms you will meet in the interface and in this documentation.

## The objects

**WhatsApp instance**
A WhatsApp number connected to KwikTalk. Contacts, campaigns and messages are
attached to an instance. You can have several.

**Contact**
A name and a phone number stored in KwikTalk.

**Contact group**
A named set of contacts ("Abidjan customers", "Trade show leads 2026"). A group is
what you target in a campaign.

**Message template** (also called *template*)
A saved, reusable message with variables, optionally with an image or a document.
You pick it when creating a campaign.

**Campaign**
A send of one template to a set of contacts, with a delay between each message,
immediately or scheduled.

**Single message**
A send to one recipient only, without a campaign.

## The states

**Pending** (contact)
Imported but not verified yet.

**Validated** (contact)
The number has been checked: it does exist on WhatsApp.

**Invalid** (contact)
The number does not exist on WhatsApp. No point writing to it: the message will
fail.

**Connected / Disconnected** (instance)
The instance talks to WhatsApp correctly, or the link is broken (phone reset,
device removed, suspension).

**Sent / Delivered / Read** (message)
*Sent*: KwikTalk handed the message to WhatsApp. *Delivered*: it reached the
recipient's phone. *Read*: the recipient opened it.

**Draft / Scheduled / Running / Paused / Completed** (campaign)
The stages in a campaign's life.

## The settings

**Delay between messages**
The wait KwikTalk respects between two sends of the same campaign (3 to 10
seconds). A short delay finishes the campaign faster but increases the risk of
suspension.

**Scheduling**
Choosing a start date and time. The time is read in the **time zone** you select.

**Quota**
The maximum number of objects your plan allows: instances, contacts, campaigns,
templates, API applications. See [Plans and quotas](/en/billing/plans).

**Wallet**
Your prepaid balance in KwikTalk, used to pay the subscription and top-ups. It is
distinct from the **subscription**, which is your plan.

## On WhatsApp's side

**Multi-device**
WhatsApp Web mode: a linked device can send messages even when the phone is off.

**QR code**
The code to scan from WhatsApp to link a device. It expires: regenerate it.

**Pairing code**
An alternative to the QR code: an 8-character code to type into WhatsApp to link
the device.

**Ban**
WhatsApp suspending a number, usually for bulk sending or recipient complaints.
See [Avoiding bans](/en/help/anti-ban).
