A **free tool, no account needed**: write your message, format it, paste it into
WhatsApp exactly as is.

Access: **`/outils/formatteur-whatsapp`**

::u-alert{color="success" icon="i-lucide-gift"}
No sign-up, no login. The tool works for everyone, including people without a
KwikTalk account.
::

## The syntax

WhatsApp has no toolbar: formatting uses special characters. The formatter
applies them for you.

| Format | WhatsApp syntax | Result |
|---|---|---|
| **Bold** | `*text*` | **text** |
| *Italic* | `_text_` | *text* |
| ~~Strikethrough~~ | `~text~` | ~~text~~ |
| List | `•` lines | bulleted list |
| Quote | `> ` line | quotation |

::u-alert{color="info" icon="i-lucide-info"}
Lists and quotes are handled in addition to the three character styles. Everything
is produced in the native format: once pasted, WhatsApp renders it directly.
::

## How to use it

1. **Your text** — type or paste your message in the left panel.
2. Apply **Bold**, **Italic** or **Strikethrough** to the selection.
3. The **formatted result** appears on the right, with the WhatsApp preview.
4. Click **Copy** — the message lands in the clipboard in WhatsApp format.

Available actions: **Copy**, **Clear**, **Preview**, and an **Example** to see
how it works right away.

## The character counter

The tool displays the **number of characters** in your message and permanently
reminds you:

::u-alert{color="warning" icon="i-lucide-ruler"}
**WhatsApp message limit: 4096 characters.**
::

Beyond that, WhatsApp truncates. This is also the limit applied by the KwikTalk
API (`message` field, 4096 characters) — see
[API applications](/en/integrations/api-applications).

::u-alert{color="info" icon="i-lucide-lightbulb"}
The counter includes the formatting characters (`*`, `_`, `~`). A visually short
message can therefore hit the limit faster than it looks — copy first, then check.
::
