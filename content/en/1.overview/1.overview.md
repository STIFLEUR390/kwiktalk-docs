KwikTalk is a **WhatsApp marketing platform**. It lets you run one or more
WhatsApp numbers, import a contact base, send individual messages or bulk
campaigns, and connect the whole thing to your tools through an API and webhooks.

::u-alert{color="info" icon="i-lucide-info"}
KwikTalk runs on **WhatsApp Web** (multi-device mode). You scan a QR code, your
number stays connected, and messages are sent from your own account.
::

## What you can do

| Area | Feature |
|---|---|
| Numbers | Connect several **WhatsApp instances** via QR code, track their state in real time |
| Contact base | Import an **Excel** file, validate numbers, organise into **groups** |
| Content | Create **templates** with dynamic variables |
| Sending | Individual messages, bulk **campaigns** with scheduling |
| Replies | Collect **incoming messages**, answer from the UI |
| Automation | **Chatbot** by rules or workflow, excluded numbers, group scoping |
| Integration | Versioned **REST API**, HMAC-SHA256 signed **webhooks** |
| Safety | **Anti-ban** protection with preventive quotas and ban handling |

## How it is structured

The product is built on a small number of entities:

```
WhatsApp instance  ←  owned by a user account
├── Contacts (+ groups)
├── Message templates
├── Messages (individual)
├── Campaigns (bulk sends)
├── Incoming messages (replies)
├── API application (key, bound to ONE instance)
└── Webhooks (event endpoints)
```

An **instance** is the core unit: it carries the WhatsApp number. Contacts,
templates and campaigns hang off it. An **API key** is also bound to a single
instance — calls always go through the right number.

## Who can access what

KwikTalk grants rights by **permission**, not by a fixed menu.

::u-alert{color="warning" icon="i-lucide-shield-alert"}
This documentation covers **public pages** (no account) and **the `user` role** —
the full workspace of a regular user. Platform administration belongs to the
`admin` and `super-admin` roles and is not described here.
::

The `user` role has every operational feature:

- dashboard
- WhatsApp instance management
- contacts and groups
- message templates
- sending and tracking messages
- creating and running campaigns
- incoming messages
- API applications
- chatbot
- webhooks
