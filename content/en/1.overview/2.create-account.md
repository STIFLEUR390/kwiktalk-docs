## Sign up

1. Go to the KwikTalk registration page.
2. Enter your name, e-mail address and a password.
3. Submit.

::u-alert{color="info" icon="i-lucide-mail"}
Access to the dashboard goes through the `verified` middleware: **your e-mail
address must be verified** first. A verification e-mail is sent right after
registration.
::

If you did not click the link, you can resend it from the verification page, or
request a reset from **"Forgot password"**.

## Sign in

The login page accepts:

- **e-mail + password**
- **Authentik (OIDC)** — if your organisation enabled federated login, a button
  redirects you to Authentik, and a callback brings you back authenticated.

::u-alert{color="warning" icon="i-lucide-key-round"}
KwikTalk supports **two-factor authentication (2FA)**. If it is enabled on your
account, signing in also requires a one-time code.
::

## What waits for you on first login

A **onboarding tour** guides you, in this order:

| Step | Goal |
|---|---|
| `welcome` | Welcome and tour introduction |
| `whatsapp` | Connect your first WhatsApp instance (QR code) |
| `templates` | Pick or create a message template |
| `personalize` | Personalise the content |
| `test` | Send a test message |

You can resume it any time from **`/onboarding`**.
See [First steps](/en/overview/first-steps).

## Language

The UI and public pages are **bilingual French / English**. Change the language
from the header selector; your choice is remembered.
