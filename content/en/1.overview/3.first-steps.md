The onboarding runs at **`/onboarding`** and has five steps. It resumes where you
left it.

## 1. `welcome` — Welcome

Tour introduction. Nothing to configure.

## 2. `whatsapp` — Connect a number

The most important step.

1. Create the **WhatsApp instance**: give it a recognisable name
   ("Sales", "Support", "Rep 1"…).
2. A **QR code** is generated. Open WhatsApp on your phone →
   **Linked devices** → **Link a device** → scan the code.
3. Wait until the status becomes **connected**.

::u-alert{color="warning" icon="i-lucide-qr-code"}
The QR code expires quickly. From the UI you can:

- **Regenerate the QR code** (`instance.regenerate-qr`) if it expired;
- **Reset the instance** (`instance.reset`) if pairing failed;
- **Refresh the status** (`instance.refresh-status`) without reloading the page.
::

::u-alert{color="info" icon="i-lucide-smartphone"}
The instance stays connected in **multi-device mode**: your phone can be
offline, WhatsApp Web keeps working.
::

Details: [WhatsApp instances](/en/features/whatsapp-instances).

## 3. `templates` — Pick a template

Select an existing **message template** or create one. The template defines the
message body and its variables.

## 4. `personalize` — Personalise

Adjust the content for your use case. Variables are filled in at send time.

## 5. `test` — Send a test message

Send a message to **your own number** (or a test number) to validate the whole
chain: instance connected, template correct, message delivered.

::u-alert{color="success" icon="i-lucide-check-circle"}
Once the test arrives, complete the onboarding (`complete`). You land on the
[Dashboard](/en/account/dashboard).
::
