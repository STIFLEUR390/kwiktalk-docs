An **instance** is KwikTalk's core unit: it carries a WhatsApp number. Contacts,
templates, campaigns and API keys are bound to it.

Access: **`/admin/whatsapp-instances`**

## Create an instance

1. Go to **WhatsApp instances** → **Create**.
2. Give it a name (it appears throughout the UI).
3. The instance is created — it still needs connecting.

## Connect the number

1. Open the instance.
2. A **QR code** is displayed.
3. On the phone: **WhatsApp → Linked devices → Link a device**.
4. Scan the code.

::u-alert{color="info" icon="i-lucide-qr-code"}
Three actions are available if pairing does not go well:

| Action | When |
|---|---|
| **Regenerate the QR code** | The code expired |
| **Reset the instance** | Pairing failed or the state is inconsistent |
| **Refresh the status** | Check state without reloading the page |
::

## Track the state

An instance exposes its connection history:

- `last_connected_at` / `last_disconnected_at`
- `reconnect_count` — number of automatic reconnections
- `banned_at` / `banned_until` / `ban_reason` — if the number was **banned** by
  WhatsApp

::u-alert{color="warning" icon="i-lucide-ban"}
**A banned number**: sends are blocked and the related campaigns are
auto-paused (`anti_ban_paused_at`). You get a notification. Sending resumes by
itself when the ban lifts — see [Anti-spam protection](/en/resources/anti-spam).
::

## Sync contacts

From an instance you can **sync contacts**: KwikTalk pulls the contact list from
the linked WhatsApp account and compares it to your base. See
[Contacts and groups](/en/features/contacts-groups).

## Dead letter queue (DLQ)

An instance has a **dead letter queue**: messages whose send failed permanently
end up there, and **each entry can be replayed** individually.

This is the first thing to check when a bulk send fails: open the instance DLQ,
then replay the entries once the cause is fixed.

## Multiple numbers

The number of simultaneous instances depends on your plan:

| Plan | Instances |
|---|:---:|
| Starter | 1 |
| Growth | 5 |
| Business | ∞ |
