A **template** is a stored, reusable message used for individual sends and for
campaigns.

Access: **`/admin/message-templates`**

::u-alert{color="info" icon="i-lucide-layers"}
The template applies to both the **text body** and the **media caption**
(`media_caption`): one personalisation covers both.
::

## Create a template

1. **Templates → Create**.
2. Name it (internal, used to find it again).
3. Choose the **type**: plain text, image, document…
4. Write the content, inserting variables if needed.
5. Save.

Media fields (`media_url`, `media_filename`, `media_mimetype`, `media_caption`)
are filled in when the template carries an attachment.

## Variables

Only **two variables** are supported today:

| Variable | Replaced with |
|---|---|
| `{name}` | The contact's name |
| `{phone}` | The contact's phone number |

::u-alert{color="warning" icon="i-lucide-case-sensitive"}
Variables are **case-sensitive**: `{Name}` will **not** be replaced. Only
`{name}` and `{phone}` work — any other brace stays literal in the sent message.
::

Precise behaviour:

- **All** occurrences are replaced.
- If the contact data is missing, the variable becomes an **empty string** (so
  the message never contains `{name}`).
- Values are **escaped**: the editor produces HTML, and escaping keeps the markup
  valid before the WhatsApp conversion.

### Example

```
Hello {name}, your order is ready.
We are reaching you at {phone}.
```

Result for "Awa" at `+225 07…`:

```
Hello Awa, your order is ready.
We are reaching you at +225 07….
```

## Use a template

- **Individual send**: from [Messages](/en/features/messages-campaigns), pick the
  template, then the recipients.
- **Campaign**: the template is selected when creating the campaign.
- **Onboarding**: the first-run tour offers to pick and personalise a template.

## Quotas and organisation

| Plan | Templates |
|---|:---:|
| Starter | 5 |
| Growth | 50 |
| Business | ∞ |

Each template has a **status** (`status`) and an `active` flag: you can keep a
template ready without exposing it in the pickers.

## Deletion

- **One template** — from its detail page.
- **All templates** — bulk action from the list.

::u-alert{color="warning" icon="i-lucide-triangle-alert"}
Bulk deletion is **permanent**, and running campaigns that reference a deleted
template will no longer resolve it. Check usage first.
::
